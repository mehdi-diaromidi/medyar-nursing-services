# پنل ادمین (wp-admin)

وضعیت: **فقط بریف کلی + پیامدهای صفحات دیگر**؛ جزئیات UI در چت طراحی نشد. کد: منوی «خدمات پرستاری» (`mns-dashboard`, cap `manage_mns`, position 27) با زیرمنوهای stub: پیشخوان، رصد مرکزی (`mns-monitor`)، تخصیص، عضویت پرستاران، سفارش تلفنی، مالی و گزارش، تنظیمات. fixture: `admin/static-fixtures/hub.php`. ظاهر استاندارد وردپرس (`WP_List_Table`، CSV/Excel، تاریخ شمسی).

## اکشن‌های ادمین
A-16 تغییر پرستار/زمان/لغو (با دلیل؛ گزینهٔ «به حساب نرخ لغو پرستار بیاید؟» پیش‌فرض خیر) · A-17 صدور فاکتور دستی · A-18 ثبت پرداخت دستی (نقدی/کارت‌به‌کارت + شمارهٔ پیگیری) · A-19 یادداشت داخلی · برگرداندن شروع/پایان اشتباه · باز کردن قفل چک‌لیست/دارو (فقط قبل پرداخت) · ویرایش فاکتور پرداخت‌نشده · برداشتن علامت «نیازمند بررسی» · تأیید عکس پروفایل پرستار.

## رصد مرکزی
سفارش‌های دارای علامت فوری یا «نیازمند بررسی» بالا و رنگ‌برجسته؛ خطاهای ارسال پیامک؛ سفارش‌های «بدون پرستار»؛ کارت‌های بالای داشبورد: منتظر پرستار، پرونده‌های نارضایتی دیرکرده [پیشنهاد اولیه]، برداشت‌های در انتظار، فوری‌ها.

## گزارش‌ها
سفارش‌ها · فاکتور و پرداخت · رضایت · نارضایتی · **عملکرد پرستار: تعداد خدمت، سه میانگین امتیاز، لغو (بدون تأخیر)** · مالی و مبالغ قابل تسویه · تقاضای برآورده‌نشده بر اساس جنسیت/منطقه/خدمت [ایدهٔ ردشده/اختیاری]. خروجی CSV/Excel.
