30. پایان خدمت = اعلام پرستار، بدون کد — [قطعی]
31. مدت خدمت محاسبه و ثبت می‌شود (`duration_minutes`)؛ روی قیمت اثر ندارد؛ به بیمار نشان داده نمی‌شود؛ هشدار «هنوز در حال انجام» پس از ۸ ساعت (قابل تنظیم) — [قطعی]
32. روز خدمت تمام شد و شروع نشد → خودکار «نیازمند بررسی» — [قطعی]
33. شروع/پایان اشتباه را فقط ادمین برمی‌گرداند (لاگ + اعلان داشبورد پرستار) — [قطعی]
