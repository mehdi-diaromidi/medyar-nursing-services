# ۰۶ — رجیستری تنظیمات (S-xxx)

> **قانون:** هر عددی که ممکن است عوض شود در تنظیمات است، نه در کد. تنظیمات در option `mns_settings` (آرایهٔ کلید→مقدار) با `MNS_Settings::get($key)` و **رجیستری مرکزی** `MNS_Settings::definitions()` (کلید، نوع، پیش‌فرض، اعتبارسنجی، گروه) — هیچ `get_option('mns_settings')` پراکنده نه. صفحهٔ ادمین «تنظیمات» از همین رجیستری ساخته می‌شود. مقدار ناشناخته/نامعتبر ⇒ پیش‌فرض.
> ستون «مالک» یعنی چه کسی مقدار نهایی را می‌دهد؛ تا آن موقع پیش‌فرض اجرا می‌شود.

## تخصیص و دسترسی
| کلید | پیش‌فرض | توضیح / وضعیت |
|---|---|---|
| `S-ASG-MODE` `assignment_mode` | `manual` | `auto`/`manual` (قطعی: کلید سراسری) |
| `S-ASG-WEIGHTS` | `{prev:35,rating:30,fair:20,cancel:15}` | [فرض؛ مالک تأیید کند] |
| `S-CAP-SLOT` | `1` | ظرفیت هر بازه برای هر پرستار (فرض تأییدشده) |
| `S-SLOTS` `slots` | ۶ بازه: `0-4`(closed) ، `4-8` صبح زود، `8-12` صبح، `12-16` ظهر، `16-20` عصر، `20-24` شب با `start_hour/end_hour` | ساعت‌ها قابل‌تنظیم؛ UI برچسب `4:00 – 8:00` را از این می‌سازد (قطعی ۶ بازه) |
| `S-SCH-HORIZON` | `90` روز | افق ویرایش برنامه |
| `S-ORD-HORIZON` | `30` روز | افق ثبت سفارش بیمار |
| `S-START-BEFORE` | `60` دقیقه | شروع مجاز از چند دقیقه قبل از شروع بازه (قطعی: یک ساعت) |
| `S-A13-RATE` | `30/min/user` | |
| `S-ORD-CODE-DIGITS` | `5` | به‌صورت خودکار ۶ می‌شود (R-ORD-2) |

## مناطق و مکان
| `S-REG-DISTRICTS` | `{ "THR|تهران": ["منطقه 1"…"منطقه 22"] }` | شهرهای منطقه‌دار (ادمین تعریف می‌کند؛ فعلاً تهران) |
