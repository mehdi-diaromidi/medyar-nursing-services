# ۱۰ — سناریوهای پذیرش (AC-xxx)

> قالب Given/When/Then. هر AC باید (۱) در صفحهٔ **Self-test** (دادهٔ موقت علامت‌دار `mns_selftest`، پاک‌سازی خودکار) و/یا (۲) به‌صورت **دستی در مرورگر روی develop** قابل‌اجرا باشد. ستون «ابزار»: `ST` = self-test، `BR` = مرورگر. آیتم‌های M4+ فقط عنوان‌اند.
> شناسه‌های داده‌ٔ تست: پرستار A/B/C (زن)، پرستار D (مرد)، بیمار P1/P2، خدمات S1 (سرم)، S2 (تزریقات)، بازه‌ها طبق تنظیم.

## M0 — زیرساخت
| AC | سناریو | ابزار |
|---|---|---|
| AC-M0-1 | **Given** یک ماژول بک‌اند عمداً خطای نحوی دارد **When** سایت و `/wp-admin/` باز شود **Then** HTTP 200، پنل استاتیک کار می‌کند، اعلان ادمین «بک‌اند غیرفعال شد» + خطا در لاگ | BR |
| AC-M0-2 | **Given** جدول‌ها ساخته شده **When** migration دوباره اجرا شود **Then** بدون خطا/تغییر؛ `mns_db_version` درست | ST |
| AC-M0-3 | **When** «بازنشانی MNS» با عبارت صحیح **Then** جدول‌های `mns_` و فایل‌های خصوصی پاک و دوباره ساخته؛ جدول‌های وردپرس دست‌نخورده؛ بدون عبارت ⇒ رد | ST/BR |
| AC-M0-4 | **When** `MNS_Settings::set('slot_capacity','abc')` **Then** رد/پیش‌فرض؛ مقدار معتبر ذخیره و خوانده می‌شود | ST |
| AC-M0-5 | **When** endpoint ناشناس/بدون nonce **Then** `ERR_AUTH/FORBIDDEN` در envelope؛ با `?_envelope=1` همیشه HTTP 200؛ rate limit ⇒ `ERR_RATE_LIMIT` | ST |
| AC-M0-6 | **When** انتقال غیرمجاز (مثلاً `cancel` از `in_progress`) **Then** `ERR_BAD_STATE` و هیچ تغییری در DB/لاگ | ST |
| AC-M0-7 | Self-test همهٔ AC برش را اجرا و جدول PASS/FAIL نشان می‌دهد؛ دادهٔ تست پس از اجرا صفر | BR |
| AC-M0-8 | **Given** فایل خصوصی **When** URL مستقیم **Then** 403/404؛ از `/files/{id}` فقط مالک/ادمین | BR |

## M4+ (عنوان)
AC-M4: شروع (پنجره)، پایان، cron بدون‌شروع، چک‌لیست (نهایی/نسخه/بازگشایی)، دارو (نسخه/مشاوره/تأیید‌نشد)، گزارش (whitelist)، حریم · AC-M5: صدور یک‌بار، نسخه/اعتراض، پرداخت ایدمپوتنت، واریز یک‌بارهٔ سهم، رقابت پرداخت/بازگشایی · AC-M6…M7 مشابه.
