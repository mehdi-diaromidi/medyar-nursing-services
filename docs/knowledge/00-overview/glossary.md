# واژه‌نامه

| اصطلاح | معنی |
|---|---|
| MNS | Medyar Nursing Services — پلاگین خدمات پرستاری |
| ARP | affiliate-referral (طرح همکاران مدیار)؛ مرجع UI/UX |
| MSQ | Medyar SMS Queue — صف پیامک |
| MTW | Medyar Toman Wallet — کیف پول تومانی |
| پترن | قالب پیامک ازپیش‌تأییدشده با متغیر |
| fixture | دادهٔ نمونهٔ PHP برای UI استاتیک (`public/static-fixtures/`) |
| `MNS_UI_STATIC` | حالت فرانت استاتیک (بدون بک‌اند) |
| `desgin` | پوشهٔ طراحی‌ها (با همین املای غلط؛ تغییر نده) |
| کد پیگیری | `MD-xxxxx` (۵ رقم) |
| تخصیص | انتساب پرستار به سفارش |
| پایان خدمت | اعلام پرستار؛ بدون کد تأیید |
| چک‌لیست | فرم اختصاصی هر خدمت؛ مبلغ فاکتور از آن ساخته می‌شود (توکن‌ها + اقلام) |
| گزارش پایان مراجعه | فرم جدا برای مستندسازی نتیجه؛ بعد از ثبت غیرقابل‌ویرایش |
| مرحلهٔ دارو | ثبت داروی نسخه‌دار: نسخه یا مشاورهٔ تلفنی با پزشک مشخص |
| توکن | «خدمت اضافهٔ تعرفه‌دار» از پیش تعریف‌شده (مثل «کنترل فشار»)؛ پرستار فقط تیک می‌زند |
| قلم/اقلام مصرفی | کاتالوگ قیمت‌دار؛ پرستار انتخاب و تعداد می‌زند |
| «نیازمند بررسی» | وضعیت/علامت استثنا (عدم تأیید پزشک، نتیجهٔ ناقص، پایان روز بدون شروع، خطای صدور فاکتور) |
| فاکتور مکمل / پیش‌پرداخت | انواع فاکتور در طرح قدیمی دوره‌ای؛ **با حذف پیش‌پرداخت منتفی** (بنگر `inconsistencies.md`) |
| مهر / تمبر وفاداری | هر خدمت پایان‌یافته یک مهر؛ N مهر (پیش‌فرض ۵) = کد تخفیف |
| نشان (badge) | نشان مثبت پرستار؛ قواعدش بعداً تنظیم می‌شود |
| بازه (slot band) | بامداد ۰–۶، صبح ۶–۱۲، بعدازظهر ۱۲–۱۸، شب ۱۸–۲۴ (قابل تنظیم) |
| برنامهٔ دوره‌ای / نوبت | الگوی تکرار برای یک بیمار و یک خدمت / هر بار اجرای آن (یک سفارش مستقل) |
| P-xx / A-xx | شناسهٔ صفحه / اکشن در بریف چت |
| WP Rocket / LiteSpeed | لایه‌های کش سایت؛ هنگام تست `mns_nocache=1` و بالا بردن `MNS_VERSION` |
